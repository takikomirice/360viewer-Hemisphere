# シーン参照情報の先読み

2026-09-10、実際のテスト GAS `/dev` で比較した結果、先読み完了後の選択から表示までの中央値は **2700.15 ms → 181.85 ms（93.3%短縮）** となった。この結果を受け、閲覧モードでは標準で有効にする。

## 測定条件と結果

- Windows の認証済み Chrome、実際の Drive 画像・GAS を使用。
- `mode=public&delivery=direct&perf=1` を固定し、`metadataPrefetch=0` と `1` だけを変更。
- 各サイクルで新しいタブを開き、アプリ内の参照情報キャッシュをリセット。画像のブラウザ HTTP キャッシュは保持。
- 初期地点 A（`0416_1年棟、駐輪場付近`）から、B（`0416_2・3年駐輪場奥`）、C（`0416_2・3年駐輪場前`）の順で、それぞれ初回選択を測定。
- 条件の順序は無効・有効・有効・無効・無効・有効。各条件で B/C を3回ずつ、合計12回。全12回が `loaded`。
- 各ページで15秒の待機と画面確認を行ってから選択した。ツール操作時間も加わるため、厳密に同じ滞在時間ではない。有効条件では対象の先読み完了を確認した。
- `sceneStart` から `pannellumLoad` までを測定。サイドバー選択後の処理時間であり、初期ページ読み込み時間は含めない。

| 対象 | 先読みなし・中央値 | 先読みあり・中央値 |
| --- | ---: | ---: |
| B（各3回） | 2368.1 ms | 219.3 ms |
| C（各3回） | 2780.2 ms | 141.7 ms |
| 全体（各6回） | 2700.15 ms | 181.85 ms |

全記録は [metadata-prefetch-measurements.csv](metadata-prefetch-measurements.csv) に0.1 ms単位で保存。画像準備は5.6〜41.3 msと短く、先読みなしの主な待ち時間は参照情報取得（2150.3〜3880.9 ms）だった。先読みありは全6回で `hotspotSource=cache` を確認。

この比較は、画像キャッシュがあり、参照情報の先読みが完了した場合の効果を示す。画像も未取得の初回訪問や、低速回線、別ユーザーの環境に同じ短縮率を保証する測定ではない。GAS取得そのものが速くなるのではなく、選択前に実行している。バックグラウンド取得にも1件あたり数秒かかり、閲覧しない地点を含めた追加通信が発生する。取得中の地点を選んだ場合は、進行中の同じ要求を共有して残り時間を待つ。

## 実装

シーン一覧ですでに受け取っている ID・画像URLに加え、既存の `loadHotspots` から得るマーカー・方位情報を先に保持する。今回追加したキューは画像本体やBase64を取得しない。既存の画像先読み処理は別途存在する。

- 最初のシーン表示後、一覧の先頭20件までを対象に、現在地・フォルダ・有効な取得済み情報を除外して1件ずつ取得。
- シーン切替中、画面非表示中は次の先読みを待機。編集モードでは使用しない。ブラウザが報告するデータ節約設定・2G回線では新規先読みを止める。
- フォルダ移動でもバックグラウンド要求は同時1件。進行中の要求は中断せず、完了後に最新の一覧を処理する。
- キャッシュはタブ内のメモリに最大50件、取得から5分。期限切れは次の選択時に再取得。自動的に全件を繰り返し先読みする仕組みではない。
- 一覧更新・編集開始・既存の保存処理に応じてキャッシュを破棄。失敗結果は保持しない。30秒の待ち時間上限と、期限後に届く古い応答の無視を実装。
- 同じ地点の選択と先読みは1つの要求を共有し、各利用側には複製したデータを渡す。
- `metadataPrefetch=0` で自動先読みのみ無効化。`perf=1` のログで取得元（`network` / `pending` / `cache`）と段階ごとの時間を比較可能。

- ブラウザテストで標準有効化、無効との比較、取得中の選択、マーカーの保持、一覧更新を確認。
- 実GASの `/dev` で上記12回を計測。公開版 `/exec` のバージョン更新は対象外。
- 最終版はNode 432件、ブラウザ54件（先読み5件・コントロール8件・既存機能35件・サイドバー6件）で成功。サイドバーの1件はテスト内に4173番ポートが固定されていたため、4174番で実行した際に接続拒否となり、規定ポートで再実行して成功した。

- `metadataPrefetch` / `delivery` を指定しない `mode=public&perf=1` でも、地点Bで `delivery=auto`・`hotspotSource=cache`・180.6 msを確認。テーマ切替とコントロール表示も確認した。
