# v3.0.0 — サムネイルとシーン切り替えを刷新

シーンを写真から選べるサムネイル一覧を追加し、シーンジャンプや写真・音声スポットを開く際の待ち時間を改善しました。v2.1.1からの変更をまとめたメジャーリリースです。既存のシート・画像・ホットスポットは引き続き利用できます。

## 主な変更

### 写真で選べるシーン一覧

- サムネイルと名前を重ねた写真カードで、移動先を見つけやすくしました。
- PCではサイドバー幅をドラッグやキーボードで調整でき、幅をブラウザーに保存します。スマートフォンでは下部のシーン一覧を維持します。
- サムネイルは表示中のシーンを優先しながら取得します。閲覧時は読み取りだけを行い、編集時に不足分をDriveへ保存します。

### シーン移動と添付の待ち時間を改善

- サムネイルのホバー・フォーカスから画像を先読みし、ジャンプ先のマーカー・方位情報も優先して準備します。
- 写真・音声の重複した取得要求をまとめ、取得済み・取得途中の添付をシーン間で再利用します。取得済み写真4件・音声2件を最大5分保持し、編集・保存・一覧更新時は対象キャッシュを無効化します。
- 通常の写真・音声先読みは同時2件まで。3Gでは同時1件に抑え、データ節約・2G・編集モードでは自動先読みを行いません。
- public閲覧のフォルダ一覧は既存のサーバーキャッシュを利用します。編集時・手動更新時には再同期し、手動更新後は子フォルダも次回表示時に再同期します。
- 速度優先の画像変換、再訪時の画像取得経路、GAS内部の重複読み取りを改善しました。

### 添付保存と操作性を修正

- 長時間編集した後に認証トークンが期限切れになり、選択済みの写真・音声を保存できなくなる問題を修正しました。明示的な認証拒否時だけセッションを更新して再試行し、入力内容を保持します。
- 音声ファイルを直接選択できるようにし、必要なときに音声エディタを開く流れを整理しました。
- 画像読み込み失敗時の互換表示による再試行、シーン切り替え中のボタン表示、テーマ切り替えを改善しました。
- 写真削除の確認、キーボード操作とフォーカス、ジャイロの利用可否表示、クイズの写真・音声表示を改善しました。
- ホットスポット更新時に不要なシート書式設定を繰り返さず、既存のinfoレイアウトを維持します。

## 性能検証

実際のテストGAS・Chromeで比較しています。以下は特定の端末・回線・キャッシュ条件での少数試行であり、初回起動やすべての環境で同じ速度になる保証ではありません。

| 操作・条件 | 改善前 | 改善後 |
|---|---:|---:|
| 先読み後のシーンジャンプ | 約3.46秒 | 約0.20〜0.22秒 |
| 取得済み音声のシーン再訪後の再生準備（2回） | 5.95〜8.94秒 | 29〜30ms |
| 16件のフォルダ一覧API（各2回の平均） | 5.60秒 | 2.02秒 |

音声は実際の発音ではなく再生準備まで、フォルダは同じルート一覧APIの取得までを計測しています。詳細は[ジャンプと添付の先読み](https://github.com/takikomirice/360viewer-Hemisphere/blob/v3.0.0/docs/hotspot-prefetch-performance.md)、[シーン再訪時の添付](https://github.com/takikomirice/360viewer-Hemisphere/blob/v3.0.0/docs/hotspot-media-revisit-performance.md)、[追加の読み込み検証](https://github.com/takikomirice/360viewer-Hemisphere/blob/v3.0.0/docs/loading-performance-followup.md)を参照してください。

## 互換性と更新方法

- v3.0.0は閲覧体験の大きな更新に合わせたバージョンです。既存のconfig・info・scenesの保存形式や編集権限を破壊的に変更するものではありません。
- Apps Scriptへ `Code.js`、`index.html`、`styles.html`、`app.html`、`appsscript.json`、`delivery-lab.html`、`progressive-client.html` の7ファイルを反映してください。claspの利用を推奨します。既存のシートやDrive画像を作り直す必要はありません。
- リリースのAssetsにある `Hemisphere-v3.0.0-gas.zip` は、GAS用7ファイルとREADME・ライセンス文書をまとめた配布用ZIPです。テストや開発ツールを含む全ソースはGitHubのSource codeから取得できます。
- v2.1.1からの更新では、画像取得に利用する外部接続権限（UrlFetchApp）の追加認可が必要になる場合があります。公開切り替え前にデプロイ所有者がテスト実行し、Googleの認可画面で必要な権限を確認してください。[GAS更新・認可の手順](https://github.com/takikomirice/360viewer-Hemisphere/blob/v3.0.0/docs/codex-gas-workflow.md)も参照してください。
- 公開中のWebアプリを更新するには、Apps Scriptの既存デプロイを新しいバージョンへ更新してください。GitHubのリリース作成や `clasp push` だけでは、公開 `/exec` は切り替わりません。
- Driveへ外部から追加した画像をすぐ表示したい場合は「シーン一覧を更新」を押し、子フォルダならその後に開き直してください。通常閲覧では一覧キャッシュが最大5分残る場合があります。

## 検証と制約

- Node単体テスト：460件成功、失敗0件。
- Playwright全体：371件中361件成功、10件スキップ、失敗0件。スキップは `UI_CAPTURE_PHASE=before/after` 指定時のみ実行する画像取得用ケースです。PC・スマホ幅、閲覧・編集、テーマ、写真・音声、シーン移動、エラーからの復帰を含むローカル検証です。
- `Code.js` 構文チェック、音声ベンダー・段階配信クライアントの同期チェック、GASソース7ファイルの読み戻し一致、独立したリリース前レビューを確認しました。
- スマートフォンの実センサー・3G実機・多数同時アクセスは未確認です。Google側の応答時間に依存する初回表示の待ち時間は残っています。
- `deliveryLab=1` の段階配信比較画面とローカル生成ツールは実験用です。通常の閲覧画面には段階配信を採用していません。初期設定とマーカー取得をまとめる試作も、安定した改善を確認できなかったため採用していません。
