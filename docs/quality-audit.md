## 合格基準

各部門100点、総合は4部門の単純平均。各部門と総合が90点以上で合格とする。
未実施・確認不能は合格扱いにせず、実環境の主要操作が未検証なら最終採点を保留する。
重大な起動不良、保存データの消失、公開側からの無権限編集が残る場合は得点にかかわらず不合格。

| 部門 | 評価内訳 |
| --- | --- |
| 操作性 | 初回表示とシーン移動25、編集と保存25、狭い画面25、キーボードと状態説明25 |
| 応答速度 | 起動25、シーン切替25、重複通信の抑制25、待機と失敗からの復旧25 |
| ボタン・機能 | 閲覧操作25、編集操作25、共有とモード別表示25、状態に合う有効化と説明25 |
| データ品質 | 必須シートと列25、IDと参照整合性25、不要データと添付管理25、更新時の保全25 |

速度は実環境の条件と計測方法を記録し、モックの応答時間をGASの実測値として扱わない。
空き行・予備列と、不要な業務データを区別する。既存データの削除は参照と退避を確認してから判断する。
