# 360° Viewer - Hemisphere

Googleサイトに埋め込み可能な360度パノラマビューア（自作Thinglink風・GAS + Pannellum）。  
360度画像（または2D平面マップ）にホットスポット（解説マーカー）を追加し、閲覧できます。
探究学習向けの**はてなモード（フリップカード型クイズ）**にも対応しています。
**コンテナバインド型**（スプレッドシートに紐づいた GAS）で動作します。

## セットアップ手順

### ① Googleドライブに360度画像を準備

1. Googleドライブに正距円筒図法（equirectangular）形式の360度画像をアップロード  
   （または、後述の**写真アップロード機能**で編集モードから直接アップロード可能）
2. ファイル（またはフォルダ）を右クリック → **「共有」** → **「リンクを知っている全員」** が **「閲覧者」** になるよう設定
3. 「リンクをコピー」でURLを控えておく
   - **単一画像**: ファイルの共有リンク
   - **複数画像**: フォルダの共有リンク（直下の画像を一覧表示）
   - **写真アップロード機能を使う場合**: config の IMAGE_DRIVE_URL には**フォルダ**のURLを設定すること（ファイルURLは不可）

---

### ② Googleスプレッドシートを作成

1. [Google スプレッドシート](https://sheets.google.com) で新しいスプレッドシートを作成

---

### ③ スプレッドシートに Apps Script を追加

1. スプレッドシートのメニュー **「拡張機能」** → **「Apps Script」** をクリック
2. 左パネルの **「+ファイル」** から次の5ファイルを作成: `Code.js`, `index.html`, `styles.html`, `app.html`, `appsscript.json`
3. このリポジトリの各ファイルの内容を、同名ファイルに貼り付ける（`Code.js`, `index.html`, `styles.html`, `app.html`, `appsscript.json`）
   - **注意**: `index.html` が `<?!= include("styles") ?>` と `<?!= include("app") ?>` で `styles.html` と `app.html` を読み込むため、これら3ファイルはすべて必要です
4. （任意）一括入力用シート連携を使う場合: スプレッドシートで **「初期設定」** メニュー → **「一括入力用スプシを新規作成・紐づけ」** を実行すると自動作成・紐づけされる（手動で既存スプシを紐づける場合は、Apps Script のスクリプト プロパティに `STUDENT_SHEET_ID` を登録する必要がある）

---

### ④ 初期設定シートを生成し、画像URLを設定

1. スプレッドシートに戻り、**「初期設定」** メニュー → **「初期設定シートを生成」** を実行
2. **「config」** シートの **B2 セル** に、①でコピーしたGoogleドライブのURLを入力
3. 同時に `config` シートの `EDIT_KEY` が自動生成され、`WEB_APP_URL` 行も用意されます。通常、`EDIT_KEY` は手入力不要です。

---

### ⑤ Webアプリとしてデプロイ

1. Apps Script エディタに戻り、右上の **「デプロイ」** → **「新しいデプロイ」** をクリック
2. 設定:
   - **種類**: ウェブアプリ
   - **次のユーザーとして実行**: 自分（スプレッドシートへのアクセス権限が必要）
   - **アクセスできるユーザー**: Googleサイトで使う範囲に応じて選択
     - 校内のみ: `組織内の全員`
     - 一般公開: `全員`
3. **「デプロイ」** をクリック → 表示された **ウェブアプリURL**（末尾が `/exec` のURL）を控えておく
4. スプレッドシートに戻り、**「初期設定」** メニュー → **「WebアプリURLを設定」** で、控えた `/exec` URLを `config` シートの `WEB_APP_URL` に保存する

### ⑥ 編集URL・公開URLを用意

編集キーは基本的に `config` シートの `EDIT_KEY` で管理します。初期設定時に `EDIT_KEY` が自動生成されるため、先生が Apps Script のスクリプト プロパティを触る必要はありません。

WebアプリURLは `config` シートの `WEB_APP_URL` で管理します。`WEB_APP_URL` には、デプロイ済みWebアプリの末尾が `/exec` のURLを貼り付けてください。学校ドメイン環境では `ScriptApp.getService().getUrl()` が期待したURLや最新デプロイURLと異なる場合があるため、`WEB_APP_URL` の設定を推奨します。

スプレッドシートの **「初期設定」** メニュー → **「編集URLを表示」** を実行すると、`WEB_APP_URL` と `EDIT_KEY` から編集URLを確認できます。`WEB_APP_URL` が未設定の場合のみ、Apps Script が返すURLを fallback として使います。

- **編集URL例**: `https://script.google.com/macros/s/xxxxx/exec?mode=edit&editKey=YOUR_EDIT_KEY`
- **公開URL例**: `https://script.google.com/macros/s/xxxxx/exec?mode=public&delivery=direct`
- 編集URLは Classroom などで共同編集者に共有する想定です。`EDIT_KEY` を変更しない限り、同じ編集URLを継続して使えます。
- `editKey` は個人認証ではなく共有鍵です。編集URLを知っている人は編集できます。
- Apps Script のスクリプト プロパティ `EDIT_KEY` は後方互換・上級者向けとして残しており、設定されている場合は config シートより優先されます。
- 共有URL、iframe、QRも `WEB_APP_URL` を元に作ります。`WEB_APP_URL` を変更したら、共有URL・QRもそのURLを元に更新されます。
- 6時間で切れるのは `EDIT_KEY` ではなく、一時的な編集トークンです。開きっぱなしで編集できなくなった場合は、同じ編集URLを再読み込みしてください。
- **「編集キーを再生成」** を実行すると `config` シートの `EDIT_KEY` が新しい値に変わり、古い編集URLは使えなくなります。授業中の再生成には注意してください。
- 通常のWebアプリURLでは編集ボタンは表示されず、閲覧専用として開きます。
- public URL、iframe、QRには `editKey` を含めないでください。
- `mode=public` / `mode=internal` / modeなしでは編集トークンを発行しません。
- 公開・埋め込みビューからブラウザコンソールで編集系APIを呼んでも、GAS側の `assertEditToken_()` により拒否されます。

画像配信方式は `delivery` パラメータで指定できます。未指定時は `direct` です。

- `delivery=direct`: Drive直リンクで表示する通常モード。最速で、学校内運用の標準です。
- `delivery=auto`: まずDrive直リンクで試し、失敗時のみBase64 fallbackを試す互換モードです。Googleサイト埋め込みやブラウザ相性に備える場合に使います。
- `delivery=base64`: 最初からBase64 Data URIを使う強制互換モードです。遅くなるため常用しないでください。

Base64は権限突破ではありません。GAS実行者が画像にアクセスできない場合は、Base64でも表示できません。

- **標準の公開URL例**: `https://script.google.com/macros/s/xxxxx/exec?mode=public&delivery=direct`
- **互換用公開URL例**: `https://script.google.com/macros/s/xxxxx/exec?mode=public&delivery=auto`
- **強制Base64公開URL例**: `https://script.google.com/macros/s/xxxxx/exec?mode=public&delivery=base64`

ビューア右上の **「共有」** ボタンから、公開用のURL、iframeコード、またはQRコードを作成できます。共有モーダルで生成されるURLは常に `mode=public` になり、編集用の `editKey` は含まれません。

- **URL共有**: Classroom、Googleスライド、チャットなどにURLをそのまま貼る場合に使います。
- **iframe共有**: GoogleサイトなどでHTML埋め込みを使う場合に使います。
- **QR共有**: スマホ閲覧用に、public URL のQRコードを画面内に表示します。編集URLや `editKey` はQRコードに含めません。
- **画像配信**: `delivery=direct / auto / base64` を選択できます。通常は `direct`、埋め込み先との相性問題がある場合は `auto`、最終手段として `base64` を使います。
- **画質**: 共有時には選択しません。共有URLは短く保ち、閲覧後に画面右上の画質切替ボタンで速度優先/高画質を変更できます。共有URLのデフォルトは速度優先です。
- **共有対象**:
  - **ホームから**: `scene`、`yaw`、`pitch` を含めず、`[HOME]` タグ付き画像または先頭画像から開始します。
  - **現在のシーンから**: フォルダモードで現在の `scene=<fileId>` を含めます。
  - **現在の視点から**: 360度ビューで現在の `scene=<fileId>`、`yaw`、`pitch` を含めます。2Dモードでは `yaw` / `pitch` は基本的に省略・無視されます。

QRコードは、共有モーダルの `delivery` と共有対象の設定に連動して更新されます。QRコードの下にはURL文字列を長く表示せず、public URLを内部的にQR化します。QRコード生成は外部QR生成APIに共有URLを送らず、ブラウザ内のSVG生成で完結します。

`scene=<fileId>` はルートのシーン一覧にある画像だけを初期表示対象にします。サブフォルダ内の画像IDは、今回の共有URL初期表示では探索せず、見つからない場合は従来どおりホーム画像に戻ります。

### 表示速度・キャッシュ

- フォルダ一覧はサーバー側で短時間キャッシュされ、Driveの一覧取得回数を抑えます。
- 画像アップロード、写真名変更、写真削除などの編集後は、関連するフォルダ一覧キャッシュを無効化します。
- public閲覧では、同一ページ内で一度取得したホットスポット取得結果をキャッシュし、同じシーンに戻ったときの再取得を減らします。
- `delivery=auto` は直リンク失敗時、または一定時間読み込みできない場合にBase64 fallbackを試します。`delivery=direct` はBase64 fallbackを行わない標準の最速モードです。
- 表示が古い場合は、ページ再読み込みまたはシーン一覧更新を試してください。Driveを外部から直接変更した直後は、短時間キャッシュの期限まで古い一覧が見える場合があります。

### ⑦ Googleサイトに埋め込む

#### 方法A（URL埋め込み）

1. Googleサイトのページを編集モードで開く
2. ビューア右上の **「共有」** ボタンで **URL** を選択し、必要に応じて `delivery` と共有対象を選んでコピー
3. 右パネルの **「埋め込む」** → **「URLを埋め込む」** にURLを貼り付け
4. **「挿入」** → サイズを調整して保存

#### 方法B（iframe 埋め込み）

1. ビューアを開き、右上の **「共有」** ボタンをクリック
2. 形式で **iframe** を選択し、必要に応じて `delivery` と共有対象を選ぶ
3. 表示された iframe コードをコピー
4. Googleサイトで **「埋め込む」** → **「HTMLを埋め込む」** にコードを貼り付け

#### 方法C（QRコード）

1. ビューアを開き、右上の **「共有」** ボタンをクリック
2. 形式で **QR** を選択し、必要に応じて `delivery` と共有対象を選ぶ
3. 表示されたQRコードをスマホで読み取るか、**「URLをコピー」** ボタンでpublic URLをコピーして配布する
4. QRコードは `mode=public` の閲覧URL用です。編集URLや `editKey` は含めません。

## 使い方

### 閲覧モード（生徒向け）

- 画面をドラッグして360度ビューを操作（2D平面マップはスクロール・ズームで操作）
- マーカーをクリックするとラベル・説明・リンク・写真などが表示される（アイコンが「クイズ」のマーカーはフリップカードが開く）
- 複数画像がある場合、トップバー左のシーン一覧で他のパノラマ／2Dマップに移動できる
- ホットスポットに「ジャンプ先」が設定されている場合、クリックで別シーンへ遷移できる
- **写真右上のボタン**:
  - **全画面**: フルスクリーン表示
  - **ホーム**: ホームシーン（`[HOME]` タグ付き画像）へジャンプ（フォルダモード時のみ表示）
  - **画質切り替え**: 低負荷（fast）⇔ 高画質（high）をトグル
  - **ジャイロ**（モバイルのみ）: スマホを傾けて視点を操作
- **共有**: 右上の「共有」ボタンで、公開用URL、Googleサイト等に貼る iframe コード、スマホ閲覧用QRコードを生成できる。共有URLとQRコードには `editKey` を含めない
- **URLパラメータ**: `?mode=internal` / `?mode=public` でトップバー非表示（埋め込み向け）、`?quality=high` / `?quality=fast` で初期画質、`?delivery=direct|auto|base64` で画像配信方式、`?scene=<fileId>` で初期シーン、`?yaw=...&pitch=...` で360度ビューの初期視点を指定可能
- `?mode=public` / `?mode=internal` / modeなしでは編集トークンを発行しないため、ブラウザコンソールから保存・更新・削除・アップロード系のGAS関数を直接呼んでも実行できません。この仕組みは個人ごとの認証・権限制御ではなく、公開ビューからの編集操作を防ぐためのものです。
- 通常のWebアプリURL（`mode` なし）で開いた場合は閲覧専用として開き、編集ボタンは表示されません。編集するには **「編集URLを表示」** から取得した `mode=edit&editKey=...` の編集URLで開いてください。`mode=edit` なのに編集できない場合は、config シートの `EDIT_KEY` または URL の `editKey` を確認してください。

### スマホ閲覧

スマホやタブレットでは `mode=public` の共有URLを使う public閲覧モードを想定しています。編集はPC推奨です。

- スマホ幅の public閲覧では、シーン一覧は下部の「シーンを選ぶ」UIから展開するボトムシート形式で表示されます。
- ホットスポットの詳細は下から出るカードとして表示され、長い説明文や写真はカード内でスクロールできます。
- ジャイロ操作に対応しており、初回表示時に短い案内を表示します。
- 2D平面マップもスマホ幅で表示できるよう、下部シーンUIと重なりすぎない配置にしています。
- 共有モーダルのQR形式で、スマホ閲覧用の `mode=public` URLをQRコードとして表示できます。編集URLのQR化は想定していません。

### 編集モード（教員向け）

1. スプレッドシートの **「初期設定」** → **「編集URLを表示」** で取得した `?mode=edit&editKey=...` の編集URLでビューアを開く
2. 右上の **「編集モード」** ボタンをクリック
3. 画面が黄色のハイライト枠に切り替わる
4. 解説を追加したい場所をクリック
5. 入力項目を設定して **「保存する」** をクリック:
   - **ラベル**（必須）
   - **詳細説明**
   - **リンク**: 外部URL（https://...）
   - **マーカー見た目**: 形（丸/四角/菱形/星）、色、アイコン（情報/写真/Wi-Fi/**クイズ**）
   - **写真**（フォルダモード時のみ）: 同フォルダ内の画像を紐付け、ホットスポット表示時に表示
   - **ジャンプ先シーン**（フォルダモード時のみ）: クリックで別の360度シーンへ移動
6. 既存のホットスポット: クリックで編集、**右クリック**で「編集」「削除」メニュー表示
7. **フォルダモード時**: シーン一覧の画像を**右クリック** → 「名前を変更」（Googleドライブ上のファイル名を変更）、「プロパティを表示」、「写真を削除」
8. **写真をアップロード**: シーン一覧上の **「⬆ 写真をアップロード」** ボタンから、360°パノラマまたは2D平面マップを直接Googleドライブに追加できる（config でフォルダURLを設定済みであること）
9. **シーン一覧の更新**: フォルダモード時、シーン一覧左端の **更新ボタン（↻）** で画像一覧を再取得できる
10. **一括入力用シート連携**（フォルダモード時）: 「入力用スプシのリストを更新」「入力用スプシを一括取り込み」で、一括入力用シートからホットスポットを登録できる（[詳細](#一括入力用シート連携)）

### はてなモード（フリップカード型クイズ）

マーカーのアイコンを **「クイズ (はてな)」** に設定すると、クリック時に通常のポップアップではなくフリップカードが表示されます。
探究学習や現地調査で「問い→答え」を対話的に確認するシーンに活用できます。

**設定方法:**

1. 編集モードでホットスポットを追加・編集
2. 「マーカーのスタイル」パネルで **アイコン = クイズ (はてな)** を選択
3. **詳細説明** に `問題文|答え` の形式で入力（`|` でパイプ区切り）
   - 例: `この橋が架けられたのは何年ですか？|1954年（昭和29年）`
   - `|` 以降を省略した場合は「答えが設定されていません」と表示される
4. （任意）**リンク** に URL を設定すると、答え面に「さらに詳しく」リンクが表示される

**生徒の操作:**

- マーカーをクリック → 問題面のカードが開く
- カードをクリック → 裏返って答えが表示される（再クリックで問題面に戻る）
- `×` ボタン、またはカード外の暗転エリアをクリックで閉じる

### 2D平面マップについて

- ファイル名の先頭に `[2D]` が付いた画像は、360度パノラマではなく2D平面マップとして表示される
- 写真アップロード時に「2D平面マップ」を選択すると、自動的に `[2D]` プレフィックスが付く
- 2Dモードでもホットスポット（ラベル・説明・リンク・ジャンプ先など）は同様に利用可能

### ホームシーン（[HOME]タグ）

- フォルダモード時、ファイル名に `[HOME]` を含む画像を「ホームシーン」として識別する
- 例: `[HOME] 校舎入口.jpg` のようにリネームすると、写真右上のホームボタンから常にこのシーンへ戻れる
- `[HOME]` が付いた画像がなければ、フォルダ内の最初の画像がホームとして扱われる

### フォルダモードのサブフォルダ

- config にフォルダURLを設定した場合、サブフォルダ内の画像も階層的に表示される
- サイドバーでフォルダをクリックすると中身を表示し、「← 戻る」で上位フォルダに戻れる

## 一括入力用シート連携

スプレッドシートでホットスポット情報を入力し、編集モードから一括取り込みできる機能です。

### 準備

1. 一括入力用スプレッドシートを用意
   - **メニューから作成**（推奨）: **「初期設定」** → **「一括入力用スプシを新規作成・紐づけ」** を実行すると、コンテナスプレッドシートと同じフォルダ内に一括入力用スプシが自動作成され、ID が PropertiesService に保存されて紐づく。ヘッダー行・列幅・入力規則（フォルダ設定済みなら）も自動設定される
   - **既存スプシを紐づける場合**: Apps Script エディタ → **プロジェクトの設定** → **スクリプト プロパティ** で `STUDENT_SHEET_ID` にスプレッドシート ID を追加。シート名は `Code.js` の `STUDENT_SHEET_NAME`（デフォルト「シート1」）に合わせる
2. 一括入力用シートに次の列構成でテンプレートを用意（1行目はヘッダー）:

| 列 | 内容 |
| -- | -- |
| A | No（行番号など、任意） |
| B | 対象シーン（画像名） |
| C | ラベル |
| D | 説明 |
| E | リンクURL |
| F | 写真（同フォルダ内の画像名） |
| G | ジャンプ先（画像名） |
| H | 状態（取り込み済みは「済」） |

### 編集モードでの操作

- **入力用スプシのリストを更新**: ビューア編集モードのサイドバーから実行。B列・F列・G列に config のフォルダ内画像名のプルダウンを設定する（スプレッドシートの **「初期設定」** → **「一括入力用スプシの入力規則を更新」** からも実行可能）
- **入力用スプシを一括取り込み**: H列が「済」でない行を読み込み、info シートにホットスポットとして追加。取り込み後、対象行の H列を「済」に更新

### 初期設定メニュー（一括入力用）

| メニュー項目 | 内容 |
| -- | -- |
| 一括入力用スプシを新規作成・紐づけ | 新規スプシを作成し、システムに紐づける |
| 一括入力用スプシの入力規則を更新 | B・F・G列のプルダウンを更新 |
| 紐づき中のスプシIDを確認 | 現在紐づいているスプシの ID と URL を表示 |

※ フォルダモードかつ `IMAGE_DRIVE_URL` にフォルダURLが設定されている場合のみ利用可能。  
※ 一括取り込み時は Pitch/Yaw が 0 になるため、必要に応じて編集モードでホットスポットの位置を調整してください。

## トラブルシューティング

| 症状 | 確認事項 |
| -- | -- |
| パノラマ画像が表示されない | Driveの共有設定が「リンクを知っている全員」になっているか、config シート B2 に URL が入力されているか確認 |
| 保存できない | コンテナバインド型であること、スクリプトの実行権限を再確認 |
| Googleサイトに埋め込めない | デプロイ時の「アクセスできるユーザー」設定を確認 |
| ホットスポットが表示されない | スプレッドシートのシート名が `info` か確認 |
| 写真アップロードが失敗する | config の IMAGE_DRIVE_URL に**フォルダ**のURLを設定しているか確認（ファイルURLは不可） |
| 一括入力用シート連携が使えない | 一括入力用スプシが紐づけられているか（「初期設定」→「紐づき中のスプシIDを確認」で確認）、IMAGE_DRIVE_URL がフォルダ URL か、一括入力用シートに編集権限があるか確認 |
| ジャイロが使えない／表示されない | スマートフォン・タブレットのみ対応。HTTPS 環境であること、ブラウザが DeviceOrientation をサポートしていること、ユーザー許可が必要な場合あり |
| ホームボタンが表示されない | フォルダモード（IMAGE_DRIVE_URL にフォルダURLを設定）であること、画像が1件以上あることを確認 |

### 画像配信方式について

標準では `delivery=direct` として、`https://lh3.googleusercontent.com/d/{fileId}=w4096` または `=s0` を使った直接URLで画像を配信しています。
これは軽量で高速ですが、Google の非公式エンドポイントのため、Googleの仕様変更や埋め込み先・ブラウザ相性により表示できない可能性があります。

**画像が表示されない場合**は、まず `delivery=auto` を試してください。直リンクで失敗した場合のみ、GASが画像をBase64 Data URIに変換して再表示を試みます。
それでも表示できない場合の最終手段として `delivery=base64` を使えますが、読み込みが遅くなるため常用は避けてください。

Base64は権限突破ではありません。GAS実行者が対象画像にアクセスできない場合、`delivery=auto` や `delivery=base64` でも表示できません。
